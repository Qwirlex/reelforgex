# ReelForgeX

**ReelForgeX** — программа для Windows, которая превращает длинные видео в короткие вертикальные клипы строго по правилам бренд-брифа.

- Читает бриф кампании (PDF, DOCX, TXT) и превращает его в понятный список требований.
- Находит сильные моменты в видео и нарезает клипы 9:16 для TikTok, YouTube Shorts и Instagram Reels.
- Добавляет только то, что требует бриф: субтитры, обязательный текст, водяной знак, подпись с хэштегами и отметками.
- Проверяет каждый клип по правилам брифа перед публикацией.
- Публикует в YouTube Shorts или собирает готовые пакеты для ручной публикации.

## Скачать

Последняя версия — на странице [Releases](https://github.com/Qwirlex/reelforgex/releases/latest) или на сайте **[reelforgex.com](https://reelforgex.com)**.

Требования: Windows 10/11 (64-bit).

## Первый запуск

Программа устанавливается «с нуля» — без чужих аккаунтов и ключей. После установки откройте **Настройки** и подключите свои сервисы:

1. **ИИ (Gemini)** — ключ Gemini API из Google AI Studio или свой проект Google Cloud.
2. **YouTube** (необязательно) — для автопубликации Shorts.

Все настройки, ключи и токены хранятся только на вашем компьютере (зашифрованы средствами Windows) и никуда не передаются.

## Обновление

Когда выходит новая версия, программа сообщает об этом в **Настройки → Обновления**. Скачайте новый установщик и запустите его поверх текущей версии — настройки, профили и проекты сохранятся.
